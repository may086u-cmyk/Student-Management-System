# Student Management System

A robust, console-based **Student Management System** developed in C++. This project demonstrates proficiency in Object-Oriented Programming (OOP) principles, data structures, and file handling for persistent data storage.

## 🚀 Features
* **Add New Student:** Input student details (ID, Name, GPA) with instant validation.
* **Display All Records:** Formatted table output displaying all registered students neatly.
* **Search by ID:** Fast retrieval of specific student information using ID lookups.
* **Data Persistence:** Automatically saves and loads records from a local text file (`students.txt`), ensuring data isn't lost when the program closes.

## 🛠️ Tech Stack & Concepts
* **Language:** C++
* **Core Concepts:** 
  * Object-Oriented Programming (Classes, Encapsulation)
  * Standard Template Library (`std::vector`, `std::string`)
  * File I/O (`std::ofstream`, `std::ifstream`)
  * I/O Manipulation (`std::setw`, `std::left`)
